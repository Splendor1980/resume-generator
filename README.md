# Сайт-генератор резюме без опыта работы

Сайт для тех, кто ищет первую работу (школьники, студенты, выпускники колледжей/вузов, гэп-год) и не знает, что писать в резюме без опыта. Помогает найти "скрытые" навыки в хобби/интересах и объясняет, где они пригодятся.

## Статус

Прототипная стадия. Все файлы ниже — рабочие черновики для оценки тона, механик и дизайна, не production-код.

## Структура

```
data/
  ideas.json            — база связок "интерес → навыки → роли → комментарий"
                           (schema v2: category — устойчивая, examples_now — обновляемые
                           конкретные примеры игр/сериалов, освежать раз в 6-12 мес)
  about-snippets.json   — примеры фрагментов "О себе/навыки" для вдохновения,
                           размечены по persona, tone и length (short/medium/long)

prototypes/
  01-cards-board.html              — экран "листания идей" с фильтром по тегам
  02-builder-split-screen.html     — рабочая версия: резюме слева собирается
                                       вживую по мере выбора карточек справа
  03-template-compact-vs-dense.html — сравнение шаблонов резюме под разный объём текста
```

## Ключевые решения по ходу разработки

- **Монетизация**: бесплатно — генерация идей и вдохновение; платно (~50₽ или пакетом) —
  скачивание/редактирование. Рассматриваются варианты: пакет вместо разового платежа,
  бесплатный экспорт с watermark, "поделись — получи бесплатно".
- **Экономика ИИ**: основной объём (подбор идей, сборка черновика резюме) работает БЕЗ
  живого вызова ИИ — за счёт заранее подготовленной базы `ideas.json`. Живой ИИ подключается
  только на платном этапе финальной редактуры текста.
- **SEO**: интерактивный конструктор (это, по сути, SPA на JS) поисковики не индексируют.
  Реальный SEO-трафик должен идти через отдельные статические страницы, сгенерированные
  из `ideas.json` (например `/idei/kvadrokopter-pomoshnik-blogera`). Нужен SSG-фреймворк
  (рассматривался Astro) — чистый `index.html` для этого не подходит.
- **Не только лето**: изначально ниша задумывалась как "выпускники + летние подработки",
  но верно расширена до "любой, кому нечего писать в резюме" — зимние каникулы, первая
  работа после колледжа/вуза, гэп-год. Все тексты должны быть сезонно-нейтральными.
- **Актуальность примеров**: конкретные игры/сериалы/тренды быстро устаревают, поэтому в
  схеме `ideas.json` они вынесены в отдельное поле `examples_now`, не смешанное с
  устойчивой логикой (`category`, `skills`, `roles`).
- **Авторское право**: реальные резюме/тексты других людей брать нельзя ни для дизайна
  (лицензии), ни для контента (авторское право + чужие персональные данные). Вместо этого —
  собственная база примеров, сгенерированная с нуля.
- **Адаптивные шаблоны**: короткий текст ("О себе" в одну строку) не должен выглядеть как
  пустой лист А4. Решение — шаблоны на два типа: "компактный" (сайдбар, крупная типографика,
  визуальные элементы для малого объёма контента) и "плотный" (для тех, у кого есть что
  рассказать развёрнуто). Система должна сама подбирать шаблон по объёму заполненного
  контента, а не спрашивать пользователя.
- **Самозанятость**: подходит для приёма платежей от физлиц (ставка 4% НПД, лимит дохода
  2.4 млн ₽/год). Для приёма оплаты + автофискализации чеков — агрегаторы вроде ЮKassa,
  CloudPayments (сами формируют чек в "Мой налог").
